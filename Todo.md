Create a minimalistic timer app for workout.

## Functionalities
It will have these functionalities.

### Layout
- simple and minimalistic, clean, thin modern look
- default dark mode
- user can define custom color pallete with simple editor and save it  

### Localstorage saves
- your custom color pallette is saved 
- it will save your timers localstorage and use them if the page is refreshed
- it will save timer history and show you some basic stass run

### Components
- you can define times with a "circial"-like interface, or simply typing in numbers text
- defining simple timer
- defining workout timer with number of laps, working time, break time
- you can export and import your timer definition
- hiting start timer will count down time and beep 5 second before each new round 

### tech
- use react with vite
- It will be hosted on github pages and I wanted to work offline aswell as progressive web app.
